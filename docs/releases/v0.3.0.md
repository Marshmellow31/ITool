# ITool v0.3.0 — Guided exports and a redesigned desktop app

A new four-step Windows interface: **Connect → Choose media → Export → Results**, with consistent light and dark themes, the approved ITool logo, and no desktop console window.

## New in this release

- A photographic gallery with search, sorting, filters, grouping and persistent selection; keyboard, range and marquee selection remain available.
- Editable export folder names, organization choices and a visible destination tree before copying.
- **Only copy new files**, using per-device local history and SHA-256 checks of saved copies. Selected Live Photo resources are handled together.
- Optional embedded capture dates for saved-file creation/modification times, with missing-date and timezone fallbacks.
- Optional additional JPEG copies of HEIC/HEIF photos and H.264/AAC MP4 copies of supported SDR MOV/M4V videos. Originals are kept.
- Conditional Albums/Favorites filters when the iPhone exposes a readable, supported Photos database snapshot.
- Shared desktop/CLI options, a 4 MiB transfer buffer, cancellation and copied/skipped/converted summaries.
- Device-free demo navigation with sample media and explicitly simulated results. README screenshots show all four screens in both themes.

## Downloads

- **ITool-v0.3.0-windows-x64.zip** — desktop app, CLI, README, screenshots and release notes.
- **itool-desktop.exe** — standalone Windows desktop app.
- **itool.exe** — standalone command-line tool.
- **SHA256SUMS.txt** — checksums for the three downloads above.

Unzip to a new folder and open `itool-desktop.exe` for the regular app. Connect one trusted, unlocked iPhone using a data-capable USB cable. For sample mode, launch `itool-desktop.exe --demo`.

Requires Windows 10/11 x64, Apple Mobile Device Support through Apple Devices or iTunes, and an **NTFS** export destination. Compatible copies need local FFmpeg; MP4 conversion and video timestamps also need ffprobe. These tools are not bundled or downloaded automatically.

## Verification and limits

- Optimized Windows desktop and CLI builds completed. Light/dark demo screenshots were inspected; the documented layout corrections were resolved.
- Automated tests were not rerun at the user's request. Real-iPhone transfers, Photos database access, codec conversion, timestamp behavior and long-batch interruption still need validation on this release.
- Incremental detection compares device/path/size/filesystem dates and a checked local copy. It cannot detect source content changed without changing those metadata values, and it does not resume partial files or synchronize deletions.
- Original verification compares the received-stream hash with a local reread and checks source metadata; it is not an independent iPhone-side digest.
- Albums/Favorites depend on iOS access and schema compatibility. Cloud-only originals are not fetched.
- Compatible copies may change metadata or color. HDR videos and videos lacking color-transfer metadata are skipped for conversion; codec support depends on the installed FFmpeg build.
- Capture dates without an offset use the PC timezone. Missing or ambiguous dates are left unchanged and reported. Gallery/date-folder organization still uses device filesystem dates.
- USB 3 throughput and the benefit of the larger buffer have not been benchmarked. Demo counts and rates are simulated.

If this version regresses your workflow, use the unchanged [v0.2.0 release](https://github.com/Marshmellow31/ITool/releases/tag/v0.2.0). Keep exports in separate new folders; no phone migration is required.
